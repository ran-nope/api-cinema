# Interface notes

I kept the cinema theme where it helps name an exercise: a queue, a production, a second take. The request editor and response viewer use ordinary HTTP terms.

The light background separates navigation from the dark response viewer. Orange marks the send action, while status text carries the actual result. The diagram is illustrative, not a packet capture.

On a phone, the scene picker collapses and the storyboard becomes horizontal. Fonts come from the system. There are no customer claims or decorative statistics.
